This section is the user-facing guide for the modernized Magento Laravel application. It explains retained storefront and admin behavior in terms operators, merchandisers, support teams, and business users can verify.

The final version must cover every preserved or replaced user-visible feature from `specs/modernization/magento-feature-catalog.md`.

## Required Coverage

- Storefront browsing, search, account, cart, checkout, order, wishlist, compare, review, newsletter, CMS, and multistore workflows.
- Admin catalog, sales, customer, promotion, CMS, reports, system configuration, cache, index, user, role, import/export, tax, currency, and operations workflows.
- Edge cases, validation failures, permission failures, empty states, unavailable services, and recovery paths.
- Screenshots that match the visual baseline inventory.

## Completion Rule

A user guide page is complete only when it links to feature IDs, screenshots, expected outcomes, and known operational limits.
